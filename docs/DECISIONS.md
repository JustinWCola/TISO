## 实现取舍

- P0 CLI 仍可仅使用 Python 标准库独立运行。后端 Web 应用使用 FastAPI，网格几何使用 NumPy、ContourPy 和 Shapely。
- 距离计算沿用计划书的局部米制近似。用缓冲圆收集网格边界样本，再将几何裁剪至分析圆。含无效节点的全单元不做插值。
- 默认 Mock 使用离线 Canvas 坐标视图，可按需装载高德底图和地点搜索。前端使用普通 CSS，当前目的地可通过点击、拖动标记、坐标输入或配置高德后的搜索选择。
- 高德适配器已通过模拟 HTTP 响应验证方向和顺序恢复。真实算路、真实底图及配额扣减仍需授权的高德账号与安全代理。仅有可确认的成功响应才记录有效耗时。
- 默认单进程、单任务，结果存放在内存中。Compose 只绑定回环，公网认证与 HTTPS 由部署方提供。
