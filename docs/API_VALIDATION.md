## 2026-11-26 · P3 公交

高德公交路径规划 2.0 使用 `GET /v5/direction/transit/integrated`。文档示例对 `date/time` 使用 `YYYY-MM-DD` 和以连字符分隔的时分，对 `city1/city2` 使用 citycode。项目发送同城编码、最短时间策略 `8`、夜班车标志 `1` 和 `show_fields=cost`。文档将 `transits[].cost.duration` 描述为包含等车时间的方案耗时，单位为秒。接口请求一次只传一个起点和终点。[高德公交路径规划 2.0](https://lbs.amap.com/api/webservice/guide/api/newroute)

离线响应验证了跨午夜的日期和时分、最短有效方案、出租车方案过滤、无路线和异常字段。以下记录对应当时的综合公交原型。

本地 Compose 更新至 P3 后，经授权对上海同一组 GCJ‑02 坐标发出 4 次请求。起点为 `121.445100,31.214700`，终点为 `121.473700,31.230400`。四次均返回有效的公交与步行组合方案。

| --- | ---: | ---: |
| 2026-11-27 08:00 | 5 | 2,107 秒 |
| 2026-11-27 23:40 | 4 | 2,334 秒 |
| 2026-11-28 00:10 | 4 | 2,394 秒 |

该样本的方案数量和耗时随请求时刻变化。午夜前后仍有返回，所有方案的 `nightflag` 均为 `0`。首末班时刻、夜间实际可乘性、等待与换乘耗时的构成，以及配额扣减方式仍待核对。

随后通过本地 TISO API 提交上海人民广场 2026-11-27 09:00 前到达的公交任务。固定分析半径为 1 公里，算路预算为 24 次。任务完成并生成 1 级等时线和 2 个填色带。7 个样本均有效，其中中心为 0，另 6 个点共使用 14 次高德请求。结果提示可达区可能延伸到分析半径外。

## 2026-11-26 · 地铁 + 步行

人民广场坐标经 `/v3/geocode/regeo` 返回上海城市编码 `021`。`/v5/place/around` 的地铁分类同时返回车站与出入口，作为算路起终点时仅使用类型 `150500` 的车站。线路查询返回有方向的地铁及其他线路；使用地铁类型过滤后，从途径站取得可用于算路的 POI ID。车站详情返回的线路支持发现换乘，例如一大会址·黄陂南路关联 1 号线和 14 号线。[高德站点与线路查询](https://lbs.amap.com/api/webservice/guide/api-advanced/bus-inquiry)

在北京时间 2026-11-27 08:30 的站间验证中，1 号线车站 `BV10039895` 到 `BV10026897` 用策略 `6` 返回一条地铁方案，耗时 210 秒、距离 1,460 米。解析仅接受地铁及步行。地铁专用验证入口仍为 `uv run --locked python -m scripts.verify_amap_transit`，授权后运行须提供两个车站 POI、候选出发时间和请求上限。[高德路径规划 2.0](https://lbs.amap.com/api/webservice/guide/api/newroute)

本地 TISO 完成上海人民广场任务。到达时间为北京时间 2026-11-27 09:00，最长耗时 15 分钟，等时线间隔 5 分钟，分析半径 3.5 公里。请求不含城市编码，系统自动识别为 `021`，选中人民广场和大世界为下车站。任务在 32 次测试预算处停止，其中 20 次为站间算路，返回 6 个有效地铁站、零耗时目标点、2 级等时线和 2 个填色带。此任务未触发超时剪枝，剪枝与继续检查换乘站的行为由离线用例验证。
